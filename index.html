Dashboard · Gestión logística

Lab Nutrition

Diseñé un sistema logístico para centralizar el registro de marcas, modelos y compras. El objetivo fue reemplazar tareas dispersas por un flujo claro, con estados visibles y acciones fáciles de comprobar.

El prototipo se construyó con componentes reutilizables, variables e interacciones. Después se evaluó con usuarios y se corrigieron los puntos donde el proceso generaba dudas.

Aplicación Java · Inventario
Aplicación de escritorioProyecto académico

Tienda Nova

Desarrollé una aplicación de escritorio para organizar productos, inventario y operaciones de una tienda. El proyecto traduce reglas del negocio a clases y métodos con responsabilidades bien definidas.

La solución prioriza una estructura comprensible: validaciones antes de guardar, módulos separados y una interfaz que guía al usuario sin exponer la complejidad interna.

  • Arquitectura orientada a objetos
  • Gestión de registros y validaciones

Modelo relacional · Base de datos
Bases de datosProyecto académico

Modelo de datos comercial

Diseñé una base de datos relacional para mantener clientes, productos y ventas conectados sin duplicar información. El trabajo parte de las reglas del negocio y termina en consultas SQL listas para responder preguntas operativas.

Antes de programar las consultas se definieron entidades, claves y restricciones. La normalización hasta 3FN permitió reducir redundancias y proteger la consistencia de los registros.

  • Modelo entidad-relación y reglas de negocio
  • Normalización hasta tercera forma normal
  • Consultas, relaciones y consistencia de datos

Inventario · Alertas operativas
Gestión operativaProyecto aplicado

StockPilot

Diseñé una solución para que un pequeño negocio controle entradas, salidas y productos con bajo stock desde un solo lugar, evitando registros duplicados y compras realizadas demasiado tarde.

El caso conecta reglas de inventario, modelo SQL, movimientos trazables y un dashboard pensado para tomar decisiones rápidas con datos de prueba.

  • Control de movimientos y stock mínimo
  • Modelo relacional con historial trazable
  • Indicadores de rotación y reposición

05
Perú · Análisis geoespacial farmacéutico
Analítica geoespacialProyecto aplicado

FarmaRadar Perú

Diseñé una herramienta para comparar zonas del Perú antes de abrir una farmacia. Combina población, competencia autorizada, cercanía a establecimientos de salud, precios reportados y costos del negocio.

El resultado no promete ganancias: construye escenarios y un índice de oportunidad con fuentes públicas peruanas, fecha de corte visible y supuestos editables.

  • Mapa por departamento, provincia y distrito
  • Competencia, demanda y cercanía a IPRESS
  • Escenarios de ingresos, costos y punto de equilibrio

Reservas · Gestión de horarios
Aplicación webProyecto aplicado

CitaFácil

Diseñé un sistema de reservas para negocios que atienden por horario, como barberías o consultorios. El flujo permite consultar disponibilidad, registrar una cita y controlar cambios sin cruces de horario.

El prototipo contempla reglas de disponibilidad, estados de atención, confirmaciones y una experiencia adaptable a celular para reducir coordinaciones manuales.

  • Validación de disponibilidad en tiempo real
  • Estados: pendiente, confirmada y completada
